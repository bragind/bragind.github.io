\section*{Ключевые проекты}
\begin{itemize}
    \item \textbf{\texttt{swarm\_sim\_ws}} (Multi-agent autonomous systems): Исследовательский проект по распределённому управлению роем роботов. Стек: C++, Python, ROS 2, DDS. Моделирование поведения при ограниченной связи. Подана заявка на регистрацию ПО в Роспатент. (\href{https://github.com/bragind/swarm_sim_ws}{github.com/bragind/swarm\_sim\_ws})
    \item \textbf{\texttt{MarineDashboard}} (Marine instrumentation): Десктопное приложение для морской навигации и телеметрии. Обработка NMEA-сообщений (RMC, DBT), визуализация данных. Стек: C++, Qt 6, QML, CMake. (\href{https://github.com/bragind/MarineDashboard}{github.com/bragind/MarineDashboard})
    \item \textbf{\texttt{fusion-platform}} (Industrial Sensor Fusion): Платформа сенсорной фузии для гетерогенных датчиков. Математическое ядро для оценки состояния (EKF), синхронизация данных IMU/GPS/LiDAR. Стек: C++17, Python, Eigen, CMake. (\href{https://github.com/bragind/fusion-platform}{github.com/bragind/fusion-platform})
    \item \textbf{\texttt{MultiRotorCalc}} (UAV engineering toolkit): Инженерный калькулятор для БПЛА. Расчёт тяговооружённости, мощности висения, оптимизация конфигурации. Стек: Python, численные методы. (\href{https://github.com/bragind/MultiRotorCalc}{github.com/bragind/MultiRotorCalc})
\end{itemize}
